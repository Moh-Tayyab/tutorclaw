# Chapter 1: Variables and Print

Every program starts by storing values and showing them. In Python you
create a variable by naming it and assigning a value with `=`.

```python
name = "Aisha"
print(name)
```

- Variables have a name and a value.
- `print()` sends a value to the screen.
- Strings go in quotes; numbers do not.
